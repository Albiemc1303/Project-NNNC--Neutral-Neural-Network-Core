## Project status (2 November 2026)

Phase 0–3 document pairs: adopted architectural specifications. Phase 4 D1: adopted; D2: **conditionally adopted**. Phase 5 D1 v0.2.2: **adopted**; Phase 5 D2: mathematical candidate under development, not adopted and not yet in this repository snapshot. Phases 6–12: not represented by adopted files in this snapshot.

**Adopted** means an architectural baseline decision, not mathematical proof, implementation verification, certified continuity, consciousness, or authorization of real protected effects. Open verification and engineering obligations remain binding.

The repository is organized for readability; file relocation does not revise normative content or change adoption status. Git retains the prior commits and original root paths in history.
